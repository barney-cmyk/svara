v1.78 — Application menu now reads "Neuron Flame"

The macOS menu bar (top of screen) was still showing "VoiceInk" because Xcode auto-derives CFBundleName from the internal product name and Apple's xcconfig override family doesn't expose that key. Patched in the build pipeline: the bundle's Info.plist gets a post-build edit and is re-signed before notarisation.

  • Application menu, About box, and Force Quit dialog all read "Neuron Flame" now
  • Internal executable name stays "VoiceInk" — only visible inside the bundle and in Activity Monitor; harmless and changing it would cascade through SPM dependencies
