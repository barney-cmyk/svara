v1.84 — Fix: About tab rendered blank

v1.82/v1.83's compact About page used a layout pattern (Spacer inside .frame(maxHeight: .infinity)) that NavigationSplitView mis-measures on macOS 26 — the detail pane and sidebar both went blank when the About tab was clicked, with no way to navigate back without quitting.

Fixed by wrapping the content in a ScrollView, which gives the inner views a valid coordinate space. The compact layout (everything visible without scrolling) is unchanged.
