v1.77 — Crash-on-launch fix

v1.75 / v1.76 had two startup crashes:

  • CloudKit init tried to talk to an iCloud container that isn't yet registered with Apple — fixed by disabling sync until the container is set up. Local persistence is unaffected.
  • Legacy license flow overflowed the Keychain access stack on notarised builds. Bypassed entirely — Neuron Flame is free under GPL-3, no license check needed.

If you tried v1.75 or v1.76 and saw "Neuron Flame quit unexpectedly", grab this build and the launch crash is gone.
