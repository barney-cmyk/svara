v1.88 — Model provenance, smarter recommendations, no more old versions

Every model in the AI Models tab now shows you who made it, where they're based, and how much we trust the provenance — so you can make an informed call rather than guessing at names.

  • Origin line under each model: OpenAI · United States · via whisper.cpp / NVIDIA · United States · via FluidAudio / Apple · United States / etc.
  • Trust chip on every card — Verified for major-org models, Community for open-source ports, Custom for user-supplied endpoints.
  • Introduced YYYY-MM stamp so you know how fresh each model is.

Smarter Recommended tab:

  • Colour-coded badges — Best overall (violet) / Fastest (orange) / Most accurate (emerald) / Best for multilingual (blue) / Best cloud (slate). Each category is now visually distinct so you can scan and find what you need.
  • Recency tiebreaks — when two models have the same score, the newer one wins. Parakeet V3 now beats V2 even though they're scored identically.
  • Old versions hidden — Parakeet V2 and Whisper Large v2/v3 are no longer shown in Local view (they've been superseded by Parakeet V3 / Large v3 Turbo). Already-downloaded older variants stay visible so nothing disappears from disk.
