v1.81 — Fix: in-app updates were silently failing to install

v1.78 through v1.80 had a Sparkle re-signing bug: when the build pipeline re-signed Sparkle's helper binaries with our Developer ID cert, it stripped an embedded entitlement that Sparkle uses to find its cache directory. Symptoms were "Failed to create installation cache directory" and "Installer never started archive extraction" in the logs — visually, the in-app update would download but never finish installing.

Fixed by passing --preserve-metadata=identifier,entitlements,flags to the codesign step, per Sparkle's official guidance.

From this version onwards, Check for Updates and the new sidebar update pill will work end-to-end: download → verify → quit → swap → relaunch. No more stuck installs.
