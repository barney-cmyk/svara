v1.86 — Dynamic model registry

Neuron Flame now pulls its transcription model catalogue from a live JSON file on neuronflame.com on launch and every 24 hours. When a new Whisper variant or Parakeet release becomes worth surfacing, we add it to the registry and every running install picks it up — no app update required.

This release introduces three new models alongside the existing catalogue:

  • Whisper Large v3 Turbo (Q8) — higher-quality quantized variant, closer to full Large v3 Turbo accuracy at ~874 MB
  • Distil-Whisper Large v3 — HuggingFace's distilled Whisper. ~6× faster than v3 with 99% relative WER. English-focused.
  • Tiny English (Q5) — 32 MB quantized variant, useful for short utterances on lower-spec Macs

Under the hood: catalogue lives at neuronflame.com/models.json, fetched by RemoteModelCatalogue, merged with the hard-coded fallback list. If the fetch fails, you keep whatever was cached from your last successful refresh. Worst case is "you see the in-binary defaults", never a broken state.
