How can we help?

Neuron Flame is built and supported by one person — Barney. The fastest path to an answer is usually the docs; the second-fastest is GitHub.

📖

Read the docs

Eight pages covering install, permissions, AI enhancement, Power Mode, hotkeys, custom models, privacy, and troubleshooting. Most questions are answered there.
🔧

Troubleshooting guide

Hotkey not firing, no paste, permissions reset after rebuild, model download stuck — start here for known issues with quick fixes.
🐛

Report a bug

Open a GitHub issue with your macOS version, Mac model, Neuron Flame version, and what went wrong. Include console logs if you can.
💬

Discussions

Ideas, feature requests, "is this a bug or am I doing it wrong?" — head to GitHub Discussions. Public, searchable, helps the next person too.
📦

Direct download

The current release as a signed DMG. Drag into Applications, right-click → Open the first time. Future updates ship via the in-app updater.
📂

Read the source

Neuron Flame is open source under GPL-3. Browse the code, check what the app does on your behalf, or fork it for your own use.

Still need a human?

For things that don't fit GitHub — partnership inquiries, custom builds, or the occasional kind word — email hello@neuronflame.com. Reply times depend on whether my daughter is napping.
