FAQ

Quick answers.

Is this really free?

Yes. No subscription, no license key, no paywall. Neuron Flame is open source under GPL-3 — feel free to read the source and verify exactly what the app does on your behalf.

What's the difference between Whisper and Parakeet?

Whisper (by OpenAI, ported to whisper.cpp) supports 100+ languages and runs on any Mac. Parakeet V2 (by NVIDIA, via FluidAudio) is English-only but optimised for the Apple Neural Engine — much faster. Parakeet is the default. Switch any time on the AI Models tab.

Why does macOS warn me on first launch?

The app is self-signed, not Apple-notarized (notarisation costs $99/year and we'd rather pass that on as "free"). Right-click the app → Open → Open. macOS remembers your choice forever.

Does it work offline?

Completely. The default Parakeet model and any Whisper model you download run entirely on-device. The only thing requiring internet is optional AI enhancement via cloud LLMs — and that's purely opt-in.

Which Macs are supported?

Any Mac running macOS 14 Sonoma or later. Apple Silicon strongly recommended for Parakeet. Liquid Glass UI activates automatically on macOS 26 Tahoe; older versions get the ultra-thin material fallback.

Where can I get help?

Read the documentation first — it covers every feature in detail. For bugs or feature requests, open an issue on GitHub. For everything else, head to the support page.
